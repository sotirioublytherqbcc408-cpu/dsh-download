怎么安装
1. 解压压缩包，得到三个文件：persona.md、注册块.yml、安装说明.txt 2. 打开访达 → 按 Shift+Cmd+G → 输入 ~/.dsh/profiles/desktop/presets/ → 回车 3. 新建文件夹 dshpro，把 persona.md 放进去 4. 用文本编辑器打开 ~/.dsh/profiles/desktop/cordis.patch.yml，拉到最下面，把 注册块.yml 的全部内容粘贴进去，保存 5. 完全退出 DSH（Cmd+Q），再重新打开 6. 进「设置 → 预设」，选择 DSH Pro，开新对话即可
